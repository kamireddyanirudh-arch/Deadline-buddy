# Deadline Buddy 📅

A student-focused deadline management app designed to help you stay organized and ahead of important deadlines.

## 🚀 Current Version

**v0.1 — Initial Prototype**

### ✨ Current Features

* Animated landing page
* Deadline Buddy branding
* Welcome/login interface
* Email-based login UI
* Responsive modern design

### 🛠️ Built With

* Google AI Studio
* HTML / CSS / JavaScript

### 🎯 Planned Features

* Add and edit deadlines
* Deadline countdowns
* Priority levels
* Categories
* Calendar view
* Reminders and notifications
* Completed/overdue deadlines
* User authentication
* Cloud database
* Smart deadline planning

## 📌 Project Status

This project is currently under development.

The current version is an initial prototype. More features will be added as development continues.
